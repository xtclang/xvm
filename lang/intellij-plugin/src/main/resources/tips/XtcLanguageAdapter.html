Switch between the Ecstasy compiler and Tree-sitter

The language server analyzes Ecstasy with the Ecstasy compiler by default, which knows the code's types. Tree-sitter is the older, syntax-only adapter: it knows the code's structure and indexes the workspace, and is a fallback when the compiler adapter has trouble with a project.

Press &shortcut:xtc.selectLanguageAdapter; (Tools | Switch Ecstasy Language Adapter) to choose one. The server restarts and keeps what the open editors hold.
