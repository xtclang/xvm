Build Ecstasy with the embedded compiler or with Gradle

Embedded compiler, the default: Build, Rebuild and Run use the language server's compiler and its bundled XDK, with nothing to sync, also in a project without a Gradle build. It needs the compiler language adapter. In a project with a Gradle build, the build's own settings, such as runXtc arguments, JVM options and its XDK version, do not apply.

Gradle: Build, Rebuild and Run run the project's Gradle build, with all of its settings, as on the command line. Build needs the Gradle project linked in IntelliJ. Automatic uses Gradle when the project has a Gradle build, and the embedded compiler otherwise.

Press &shortcut:xtc.selectBuildMode; (Tools | Select Ecstasy Build Mode), or open Settings | Languages & Frameworks | Ecstasy | Build and Run, to choose. The next build or run uses the new mode, with no restart or Gradle sync.
