# Exact internal API dependencies of the compiler-backed LSP4IJ integration.
# These are risk exceptions, not public API guarantees. Keep the verifier's complete reports.
# Revisit on every LSP4IJ upgrade; do not add package wildcards or IntelliJ Platform APIs.
# Parameter names are omitted because they depend on available debug information.
# Missing classes/methods and other binary incompatibilities still fail verifyPlugin.
#
# LanguageServiceAccessor / server wrappers: identify our live connection without starting
# unrelated servers; preserve lifecycle ownership for custom requests and refactorings.
# LSPFileSupport: invalidate stale semantic caches after compiler/project changes; restarting
# the entire server would lose the document-version and request ownership guarantees.
# EditorFeature renderers: refresh hints, lenses and tokens in one coalesced read/UI pass,
# avoiding upstream's per-document scheduling storm while retaining native rendering.
# Public LanguageServerManager start/stop APIs cannot replace these connection/cache hooks.
# Remove entries when upstream exposes equivalent public APIs and the adapter migrates.
