# Ecstasy keys

On macOS, press Control+Option where these say Ctrl+Alt.

| Keys | Does |
|------|------|
| Ctrl+Alt+X, then L | Show the language server's output; again to hide it |
| Ctrl+Alt+X, then R | Restart the language server |
| Ctrl+Alt+X, then A | Switch the language adapter, in an Ecstasy editor |
| Ctrl+Alt+X, then B | Choose the build mode |
| Ctrl+F9 (macOS: Cmd+F9) | Build, in an Ecstasy editor |
| Ctrl+Shift+F10 (macOS: Ctrl+Shift+R) | Run the editor's module |

Every other Ecstasy command is in the Command Palette under **Ecstasy**.
